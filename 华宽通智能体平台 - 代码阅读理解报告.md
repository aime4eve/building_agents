#### 2.3.2 状态管理（Pinia）

**用户 Store 示例**：
```typescript
export const useUserStore = defineStore('user', () => {
  // 状态
  const token = ref<string>('')
  const userInfo = ref<LoginResponse['user'] | null>(null)
  
  // 计算属性
  const isLoggedIn = computed(() => !!token.value)
  const roles = computed(() => userInfo.value?.roles || [])
  
  // 方法
  const login = async (credentials: LoginRequest) => {
    const response = await userApi.login(credentials)
    token.value = response.data.accessToken
    userInfo.value = response.data.user
    localStorage.setItem('access_token', token.value)
  }
  
  const hasRole = (role: string) => roles.value.includes(role)
  
  return { token, userInfo, isLoggedIn, login, hasRole }
})
```

#### 聚合根实现

**AggregateRoot 基类**：
```java
@Getter
public abstract class AggregateRoot<ID extends Serializable> extends Entity<ID> {
    private final List<DomainEvent> domainEvents = new ArrayList<>();
    private Long version;  // 乐观锁

    protected void addDomainEvent(DomainEvent event) {
        this.domainEvents.add(event);
    }

    public List<DomainEvent> getDomainEvents() {
        return Collections.unmodifiableList(domainEvents);
    }

    public void clearDomainEvents() {
        this.domainEvents.clear();
    }
}
```

**Device 聚合根示例**：
```java
@Entity
@Table(name = "device")
public class Device extends AggregateRoot<Long> {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Version
    private Long version;
    
    // 业务属性
    private Long tenantId;
    private String deviceSn;
    private String deviceName;
    private DeviceStatus deviceStatus;
    private Boolean onlineStatus;
    private ActivationStatus activationStatus;
    
    // 工厂方法
    public static Device create(Long tenantId, String deviceSn, String deviceName, ...) {
        Device device = new Device();
        device.tenantId = tenantId;
        device.deviceSn = deviceSn;
        device.deviceName = deviceName;
        device.deviceStatus = DeviceStatus.INACTIVE;
        device.onlineStatus = false;
        device.addDomainEvent(new DeviceRegisteredEvent(...));
        return device;
    }
    
    // 业务方法（封装业务规则）
    public void goOnline(String ipAddress) {
        this.deviceStatus = DeviceStatus.ONLINE;
        this.onlineStatus = true;
        this.lastOnlineTime = LocalDateTime.now();
    }
    
    public void activate() {
        if (this.activationStatus == ActivationStatus.ACTIVE) return;
        this.activationStatus = ActivationStatus.ACTIVE;
    }
    
    public void lock(Long lockedBy, String reason) {
        if (this.isLocked) {
            throw new IllegalStateException("设备已被锁定");
        }
        this.isLocked = true;
        this.lockedBy = lockedBy;
        this.lockReason = reason;
    }
}
```

#### 应用服务实现

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class DeviceApplicationService {
    private final DeviceRepository deviceRepository;
    private final DeviceEventPublisher eventPublisher;

    @Transactional(rollbackFor = Exception.class)
    public Device createDevice(DeviceCreateDTO dto, Long createdBy) {
        // 1. 业务验证
        if (deviceRepository.existsByTenantIdAndDeviceSn(
            dto.getTenantId(), dto.getDeviceSn())) {
            throw new IllegalArgumentException("设备序列号已存在");
        }
        
        // 2. 调用领域工厂方法
        Device device = Device.create(
            dto.getTenantId(),
            dto.getDeviceSn(),
            dto.getDeviceName(),
            dto.getDeviceType(),
            dto.getDeviceModel(),
            dto.getDeviceCategory(),
            createdBy
        );
        
        // 3. 保存
        Device savedDevice = deviceRepository.save(device);
        
        // 4. 发布领域事件
        eventPublisher.publishDomainEvents(device);
        
        log.info("设备创建成功：deviceId={}", savedDevice.getId());
        return savedDevice;
    }
}
```

### 3.3 领域事件架构

### 4.4 规则引擎架构

**执行流程**：
```
规则表达式（字符串）
  ↓
Lexer 词法分析 → Token 流
  ↓
Parser 语法分析 → AST
  ↓
Interpreter 解释执行 → 布尔结果
  ↓
触发条件满足 → 执行动作
```

**示例规则**：
```
temperature > 30 AND humidity < 50
```

**AST 结构**：
```
     BinaryOperator(AND)
    /                  \
BinaryOperator(>)    BinaryOperator(<)
   /    \               /    \
Identifier  Literal  Identifier  Literal
(temperature) (30)   (humidity)  (50)
```

2. 前端存储：Token 保存到 localStorage

4. 后端验证：网关层 JWT 校验
5. 服务间传递：ThreadLocal 传递用户上下文
