## 关键设计决策

### 1. JPA 实体与领域模型分离

采用 DDD 最佳实践，JPA 实体仅作为持久化载体:
```java
// 领域模型 (纯 Java 类，无 JPA 注解)
public class MoldPreventionZone { ... }

// JPA 实体 (仅用于持久化)
@Entity
public class MoldPreventionZoneEntity { ... }
```

### 2. Spring Data JPA + 自定义 Repository

使用 Spring Data JPA 简化基础 CRUD，自定义方法使用 JPQL:
```java
@Query("SELECT z FROM MoldPreventionZoneEntity z WHERE z.tenantId = :tenantId AND z.deleted = 0")
List<MoldPreventionZoneEntity> findByTenantId(@Param("tenantId") Long tenantId);
```

### 3. 软删除全局过滤

使用 Hibernate 的 `@SQLRestriction` 实现软删除自动过滤:
```java
@SQLRestriction("deleted = 0")
public class MoldPreventionZoneEntity { ... }
```
