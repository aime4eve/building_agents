### 1.2 推荐方案

**推荐方案B：集成Camunda BPM**

#### 核心理由

1. **企业级成熟度**
   - 经过大规模生产环境验证
   - 支持BPMN/CMMN/DMN全套规范
   - 内置历史数据清理API，支持精细化数据保留策略

2. **Spring Cloud深度集成**
   - Spring Boot Starter自动配置
   - 支持分布式外部任务模式
   - 与Spring Security无缝集成

3. **完整工具链**
   - Camunda Modeler：可视化流程建模
   - Camunda Tasklist：任务管理界面
   - Camunda Cockpit：流程监控与分析

4. **性能优势**
   - 高并发场景下性能优于Flowable
   - 异步执行器设计高效
   - 支持水平扩展

5. **社区支持**
   - GitHub 3.8k+ stars
   - 活跃的社区和丰富的文档
   - 企业级商业支持可选

#### 技术栈

```yaml
dependencies:
  - camunda-spring-boot-starter: 7.20.0
  - camunda-external-task-client: 7.20.0
  - bpmn-js: （前端流程设计器）
```

### 2.2 通信方式选择

| 场景 | 通信方式 | 技术实现 | 说明 |
|------|---------|----------|------|
| 启动流程 | 同步 | Feign API | 需要立即获取流程实例ID |
| 查询流程状态 | 同步 | Feign API | 实时状态查询 |
| 完成任务 | 同步 | Feign API | 立即推进流程 |
| 流程状态变更通知 | 异步 | MQ Event | 解耦业务，事件驱动 |
| SLA超时告警 | 异步 | MQ Event | 告警中心订阅 |
| 规则引擎调用 | 同步 | Feign API | 获取决策结果 |

### 2.3 同步调用接口（Feign API）

```java
// 工作流引擎对外API
@FeignClient(name = "workflow-engine", path = "/api/v1/workflow-engine")
public interface WorkflowEngineApi {

    /**
     * 启动流程实例
     */
    @PostMapping("/process/start")
    ProcessInstanceResponse startProcess(@RequestBody StartProcessRequest request);

    /**
     * 查询流程实例状态
     */
    @GetMapping("/process/{processInstanceId}/status")
    ProcessInstanceStatusResponse getProcessStatus(@PathVariable String processInstanceId);

    /**
     * 完成用户任务
     */
    @PostMapping("/task/{taskId}/complete")
    CompleteTaskResponse completeTask(
        @PathVariable String taskId,
        @RequestBody CompleteTaskRequest request
    );

    /**
     * 查询用户待办任务
     */
    @GetMapping("/task/pending")
    List<TaskResponse> getPendingTasks(@RequestParam String userId);

    /**
     * 调用规则引擎
     */
    @PostMapping("/rule/evaluate")
    RuleEvaluationResponse evaluateRule(@RequestBody RuleEvaluationRequest request);
}
```

### 4.3 Java Delegate实现

```java
/**
 * 自动派单委托类 - 调用规则引擎
 */
@Component
@Slf4j
public class AutoAssignDelegate implements JavaDelegate {

    @Autowired
    private RuleEngineApi ruleEngineApi;

    @Autowired
    private NotificationService notificationService;

    @Override
    public void execute(DelegateExecution execution) {
        // 1. 获取流程变量
        String workOrderType = (String) execution.getVariable("workOrderType");
        String spaceId = (String) execution.getVariable("spaceId");
        String priority = (String) execution.getVariable("priority");

        // 2. 构造规则评估请求
        RuleEvaluationRequest request = RuleEvaluationRequest.builder()
            .tenantId(TenantId.of(execution.getTenantId()))
            .ruleSetKey("auto-assign-rules")
            .facts(Map.of(
                "workOrderType", workOrderType,
                "spaceId", spaceId,
                "priority", priority
            ))
            .build();

        // 3. 调用规则引擎
        try {
            RuleEvaluationResponse response = ruleEngineApi.evaluateRule(request);

            if (response.isSuccess()) {
                // 4. 设置流程变量
                execution.setVariable("assigneeId", response.getResults().get("assigneeId"));
                execution.setVariable("assignSuccess", true);

                // 5. 发送通知
                notificationService.sendTaskNotification(
                    (String) response.getResults().get("assigneeId"),
                    "您有新的维修工单待处理"
                );
            } else {
                execution.setVariable("assignSuccess", false);
                log.warn("自动派单失败: {}", response.getMessage());
            }
        } catch (Exception e) {
            log.error("调用规则引擎异常", e);
            execution.setVariable("assignSuccess", false);
        }
    }
}
```

```java
import com.huaquantomt.workflow.domain.model.domainevent.*;

/**
 * 流程实例聚合根
 */
@Getter
@NoArgsConstructor(access = AccessLevel.PROTECTED)
public class ProcessInstance {

    // ========== 聚合根标识 ==========
    private ProcessInstanceId id;

    // ========== 值对象 ==========
    private BusinessKey businessKey;
    private ProcessDefinitionKey processDefinitionKey;
    private ProcessInstanceState state;
    private TenantId tenantId;
    private UserId startedBy;
    private ActivityId currentActivityId;

    // ========== 时间戳 ==========
    private LocalDateTime startedAt;
    private LocalDateTime endedAt;
    private LocalDateTime updatedAt;

    // ========== 版本号（乐观锁） ==========
    private Long version;

    // ========== 领域事件 ==========
    private final List<DomainEvent> domainEvents = new ArrayList<>();

    // ========== 工厂方法：启动流程实例 ==========
    public static ProcessInstance start(
        ProcessDefinitionKey processDefinitionKey,
        BusinessKey businessKey,
        TenantId tenantId,
        UserId startedBy,
        Map<String, Object> variables
    ) {
        ProcessInstance instance = new ProcessInstance();
        instance.id = ProcessInstanceId.generate();
        instance.businessKey = businessKey;
        instance.processDefinitionKey = processDefinitionKey;
        instance.tenantId = tenantId;
        instance.startedBy = startedBy;
        instance.state = ProcessInstanceState.STARTED;
        instance.startedAt = LocalDateTime.now();
        instance.updatedAt = LocalDateTime.now();
        instance.version = 0L;

        // 注册领域事件
        instance.registerDomainEvent(new ProcessInstanceStartedEvent(
            instance.id,
            instance.processDefinitionKey,
            instance.businessKey,
            instance.tenantId,
            instance.startedBy,
            variables,
            instance.startedAt
        ));

        return instance;
    }

    // ========== 业务方法：完成任务 ==========
    public void completeTask(TaskId taskId, Map<String, Object> variables) {
        validateState();

        TaskId currentTask = getCurrentTask();
        if (!currentTask.equals(taskId)) {
            throw new IllegalStateException("Task is not current activity");
        }

        this.updatedAt = LocalDateTime.now();

        registerDomainEvent(new TaskCompletedEvent(
            this.id,
            taskId,
            this.tenantId,
            variables,
            this.updatedAt
        ));
    }

    // ========== 业务方法：完成流程 ==========
    public void complete() {
        if (this.state == ProcessInstanceState.COMPLETED) {
            return; // 幂等性
        }

        ProcessInstanceState previousState = this.state;
        this.state = ProcessInstanceState.COMPLETED;
        this.endedAt = LocalDateTime.now();
        this.updatedAt = LocalDateTime.now();

        registerDomainEvent(new ProcessInstanceCompletedEvent(
            this.id,
            this.processDefinitionKey,
            this.businessKey,
            this.tenantId,
            this.startedAt,
            this.endedAt
        ));
    }

    // ========== 业务方法：挂起流程 ==========
    public void suspend() {
        if (this.state != ProcessInstanceState.RUNNING) {
            throw new IllegalStateException("Only running process can be suspended");
        }

        ProcessInstanceState previousState = this.state;
        this.state = ProcessInstanceState.SUSPENDED;
        this.updatedAt = LocalDateTime.now();

        registerDomainEvent(new ProcessInstanceSuspendedEvent(
            this.id,
            this.tenantId,
            this.updatedAt
        ));
    }

    // ========== 业务方法：恢复流程 ==========
    public void resume() {
        if (this.state != ProcessInstanceState.SUSPENDED) {
            throw new IllegalStateException("Only suspended process can be resumed");
        }

        ProcessInstanceState previousState = this.state;
        this.state = ProcessInstanceState.RUNNING;
        this.updatedAt = LocalDateTime.now();

        registerDomainEvent(new ProcessInstanceResumedEvent(
            this.id,
            this.tenantId,
            this.updatedAt
        ));
    }

    // ========== 业务方法：取消流程 ==========
    public void cancel(String reason) {
        if (this.state == ProcessInstanceState.COMPLETED) {
            throw new IllegalStateException("Cannot cancel completed process");
        }

        ProcessInstanceState previousState = this.state;
        this.state = ProcessInstanceState.CANCELLED;
        this.endedAt = LocalDateTime.now();
        this.updatedAt = LocalDateTime.now();

        registerDomainEvent(new ProcessInstanceCancelledEvent(
            this.id,
            this.processDefinitionKey,
            this.businessKey,
            this.tenantId,
            reason,
            this.endedAt
        ));
    }

    // ========== 业务方法：更新当前活动 ==========
    public void updateCurrentActivity(ActivityId activityId) {
        ActivityId previousActivity = this.currentActivityId;
        this.currentActivityId = activityId;
        this.updatedAt = LocalDateTime.now();

        // 状态变更时发布事件
        if (this.state != ProcessInstanceState.RUNNING) {
            ProcessInstanceState previousState = this.state;
            this.state = ProcessInstanceState.RUNNING;

            registerDomainEvent(new ProcessInstanceStateChangedEvent(
                this.id,
                this.processDefinitionKey,
                this.businessKey,
                this.tenantId,
                previousState,
                this.state,
                this.updatedAt
            ));
        }
    }

    // ========== 领域事件管理 ==========
    protected void registerDomainEvent(DomainEvent event) {
        this.domainEvents.add(Objects.requireNonNull(event));
    }

    public List<DomainEvent> getDomainEvents() {
        return Collections.unmodifiableList(domainEvents);
    }

    public void clearDomainEvents() {
        this.domainEvents.clear();
    }

    // ========== 私有辅助方法 ==========
    private void validateState() {
        if (this.state == ProcessInstanceState.COMPLETED ||
            this.state == ProcessInstanceState.CANCELLED ||
            this.state == ProcessInstanceState.FAILED) {
            throw new IllegalStateException(
                "Process is in terminal state: " + this.state
            );
        }
    }

    private TaskId getCurrentTask() {
        // 从Camunda运行时获取当前任务
        // 这里简化处理，实际实现需要通过Camunda API获取
        return TaskId.of("current-task-id");
    }
}
```

## 7. SLA监控设计

### 7.1 SLA计时规则

```java
/**
 * SLA计时服务
 */
@Service
public class SLAMonitoringService {

    /**
     * 任务分配时启动SLA计时
     */
    public void startSLAClock(TaskId taskId, SLAConfigId slaConfigId) {
        SLAConfig config = slaConfigRepository.findById(slaConfigId)
            .orElseThrow(() -> new SLAConfigNotFoundException(slaConfigId));

        SLAMonitor monitor = SLAMonitor.builder()
            .id(SLAMonitorId.generate())
            .taskId(taskId)
            .slaConfig(config)
            .slaDeadline(LocalDateTime.now().plus(config.getResponseTimeLimit()))
            .responseStatus(SLAStatus.PENDING)
            .build();

        slaMonitorRepository.save(monitor);

        // 调度超时检查任务
        scheduleTimeoutCheck(monitor, config.getResponseTimeLimit());
    }

    /**
     * 调度超时检查
     */
    private void scheduleTimeoutCheck(SLAMonitor monitor, Duration limit) {
        Duration warningThreshold = limit.multipliedBy((long) 0.8); // 80%时预警

        // 预警检查
        scheduler.schedule(() -> {
            checkSLAWarning(monitor.getId());
        }, warningThreshold.toMillis(), TimeUnit.MILLISECONDS);

        // 超时检查
        scheduler.schedule(() -> {
            checkSLABreach(monitor.getId());
        }, limit.toMillis(), TimeUnit.MILLISECONDS);
    }

    /**
     * 检查SLA预警
     */
    private void checkSLAWarning(SLAMonitorId monitorId) {
        SLAMonitor monitor = slaMonitorRepository.findById(monitorId).orElse(null);
        if (monitor != null && monitor.getResponseStatus() == SLAStatus.PENDING) {
            monitor.setResponseStatus(SLAStatus.WARNING);

            // 发布领域事件（符合DDD规范）
            ProcessInstanceId processInstanceId = monitor.getProcessInstanceId();
            TaskId taskId = monitor.getTaskId();
            Duration remainingTime = Duration.between(
                LocalDateTime.now(),
                monitor.getSlaDeadline()
            );

            domainEventPublisher.publish(new SLAMonitoringWarningEvent(
                monitor.getId(),
                processInstanceId,
                taskId,
                remainingTime,
                monitor.getTenantId(),
                LocalDateTime.now()
            ));

            slaMonitorRepository.save(monitor);
        }
    }

    /**
     * 检查SLA超时
     */
    private void checkSLABreach(SLAMonitorId monitorId) {
        SLAMonitor monitor = slaMonitorRepository.findById(monitorId).orElse(null);
        if (monitor != null && monitor.getResponseStatus() != SLAStatus.COMPLIANT) {
            monitor.setResponseStatus(SLAStatus.BREACHED);

            // 发布领域事件（符合DDD规范）
            Duration overtimeDuration = Duration.between(
                monitor.getSlaDeadline(),
                LocalDateTime.now()
            );

            domainEventPublisher.publish(new SLAMonitoringBreachedEvent(
                monitor.getId(),
                monitor.getProcessInstanceId(),
                monitor.getTaskId(),
                overtimeDuration,
                monitor.getTenantId(),
                LocalDateTime.now()
            ));

            slaMonitorRepository.save(monitor);
        }
    }
}
```

### 7.2 SLA达成率统计

```java
/**
 * SLA达成率统计服务
 */
@Service
public class SLAReportService {

    /**
     * 计算SLA达成率
     */
    public SLAReport calculateSLAReport(TenantId tenantId, Period period) {
        List<SLAMonitor> monitors = slaMonitorRepository
            .findByTenantIdAndCreatedAtBetween(tenantId, period.getStart(), period.getEnd());

        int total = monitors.size();
        long compliantCount = monitors.stream()
            .filter(m -> m.getResponseStatus() == SLAStatus.COMPLIANT)
            .count();

        double responseRate = total > 0 ? (double) compliantCount / total : 0;
        double resolutionRate = calculateResolutionRate(monitors);

        return SLAReport.builder()
            .tenantId(tenantId)
            .period(period)
            .totalCount(total)
            .compliantCount((int) compliantCount)
            .responseSLARate(responseRate)
            .resolutionSLARate(resolutionRate)
            .build();
    }
}
```
