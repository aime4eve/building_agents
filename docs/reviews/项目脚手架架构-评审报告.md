**3.7 OptimisticLockRepository（乐观锁仓储接口）**

```java
public interface OptimisticLockRepository<T, ID> extends BaseRepository<T, ID> {
    default T saveWithVersion(T entity) {
        T existing = findById(getId(entity)).orElseThrow(
                    () -> new BizException(ErrorCode.RESOURCE_NOT_FOUND)
        );
        if (getVersion(existing) != getVersion(entity)) {
            throw new BizException(ErrorCode.DB_OPTIMISTIC_LOCK_FAILED);
        }
        return save(entity);
    }
}
```

**评价：**
- ✅ 提供乐观锁支持
- ✅ 使用默认方法实现
- ✅ 抛出业务异常

**⚠️ 警告项：** 默认实现存在并发问题

**问题：** 先查询再保存，存在竞态条件

**建议：** 使用JPA的@Version注解或数据库级别的乐观锁：
```java
// 在聚合根上添加@Version注解
@Version
private Long version;

// 或使用数据库级别的UPDATE ... WHERE version = ?
```

### 1. ValueObject使用示例

```java
// 方式一：使用Lombok @Value（推荐）
@Value
public class DeviceId {
    String value;

    private DeviceId(String value) {
        if (value == null || value.trim().isEmpty()) {
            throw new IllegalArgumentException("DeviceId cannot be empty");
        }
        this.value = value;
    }

    public static DeviceId of(String value) {
        return new DeviceId(value);
    }
}

// 方式二：手动实现
public final class DeviceId extends ValueObject {
    private final String value;

    private DeviceId(String value) {
        this.value = Objects.requireNonNull(value, "value cannot be null");
    }

    public static DeviceId of(String value) {
        return new DeviceId(value);
    }

    public String value() {
        return value;
    }

    @Override
    protected Object[] getEqualityComponents() {
        return new Object[]{value};
    }
}
```
