### 1. 读写分离架构评审

#### ✅ 通过项

**1.1 CQRS模式实现正确**

```
设备数据上报
    ├──► MySQL (写侧快照) - device_telemetry_snapshot
```

**评价：**
- ✅ 符合系统设计说明书的"写侧快照+读侧时序"分离策略

- ✅ 读侧：时序数据库存储历史数据，支持时间范围查询

**1.2 写入流程设计**

|------|------|------|
| 1 | 同步写入MySQL快照表 | ✅ 保证一致性 |
| 2 | 异步写入时序数据库 | ✅ 通过Kafka解耦 |
| 3 | 批量写入优化 | ✅ 提高性能 |

**1.3 查询路由设计**

**评价：**

#### ⚠️ 警告项

**5.1 数据一致性保证机制**

**问题：** 时序数据库异步写入可能失败，缺少补偿机制

**建议：** 补充数据一致性保证机制
```java
@Service
public class TelemetryWriteService {

    @Autowired
    private KafkaTemplate<String, TelemetryEvent> kafkaTemplate;

    @Autowired
    private TimeSeriesWriteFailureRepository failureRepository;

    /**
     * 写入遥测数据
     */
    @Transactional
    public void writeTelemetry(DeviceTelemetry telemetry) {
        // 1. 同步写入MySQL快照
        snapshotRepository.upsert(telemetry);

        // 2. 异步写入时序数据库
        try {
            kafkaTemplate.send("telemetry-topic", telemetry);
        } catch (Exception e) {
            // 记录失败，后续补偿
            failureRepository.saveFailure(telemetry, e);
        }
    }

    /**
     * 补偿任务：重试失败的写入
     */
    @Scheduled(fixedRate = 60000) // 每分钟执行一次
    public void retryFailedWrites() {
        List<TelemetryEvent> failures = failureRepository.getPendingFailures();
        for (TelemetryEvent failure : failures) {
            try {
                kafkaTemplate.send("telemetry-topic", failure);
                failureRepository.markSuccess(failure.getId());
            } catch (Exception e) {
                // 继续记录失败
            }
        }
    }
}
```

## 附录：建议的查询路由实现

### TelemetryQueryRouter实现

```java
package com.huakuantong.telemetry.application.service;

import com.huakuangtong.device.domain.model.valueobject.*;
import com.huakuangtong.telemetry.domain.model.*;
import com.huakuangtong.telemetry.application.repository.*;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;

import java.time.LocalDateTime;
import java.util.List;

/**
 * 遥测数据查询路由服务
 * 负责根据查询类型路由到不同的存储
 */
@Service
@RequiredArgsConstructor
@Slf4j
public class TelemetryQueryRouter {

    private final DeviceTelemetrySnapshotRepository snapshotRepository;
    private final TimeSeriesQueryService timeSeriesQueryService;

    /**
     * 获取设备最新状态（查MySQL快照表）
     */
    public DeviceTelemetry getLatest(DeviceId deviceId) {
        log.debug("Querying latest telemetry for device: {}", deviceId);
        return snapshotRepository.findByDeviceId(deviceId)
            .orElseThrow(() -> new TelemetryNotFoundException(deviceId));
    }

    /**
     * 获取设备最新指定属性值（查MySQL快照表）
     */
    public Object getLatestProperty(DeviceId deviceId, String propertyName) {
        DeviceTelemetry telemetry = getLatest(deviceId);
        return telemetry.getValue(propertyName);
    }

    /**
     * 获取历史趋势数据（查时序数据库）
     */
    public List<TelemetryPoint> getHistoryTrend(
        DeviceId deviceId,
        String propertyName,
        LocalDateTime from,
        LocalDateTime to,
        AggregationLevel aggregation // MINUTE_5, MINUTE_30, HOUR_1, DAY_1
    ) {
        log.debug("Querying history trend for device: {}, property: {}, from: {}, to: {}",
            deviceId, propertyName, from, to);

        // 路由到时序数据库
        return timeSeriesQueryService.queryHistoryTrend(
            deviceId, propertyName, from, to, aggregation
        );
    }

    /**
     * 获取空间内所有设备的最新数据
     */
    public List<DeviceLatestTelemetry> getSpaceDevicesLatest(SpaceId spaceId) {
        // 从MySQL快照表查询（空间维度快照查询）
        return snapshotRepository.findBySpaceId(spaceId);
    }

    /**
     * 获取空间内设备的数据统计（查时序数据库）
     */
    public SpaceTelemetryStatistics getSpaceStatistics(
        SpaceId spaceId,
        LocalDateTime from,
        LocalDateTime to
    ) {
        // 路由到时序数据库进行聚合统计
        return timeSeriesQueryService.querySpaceStatistics(spaceId, from, to);
    }

    /**
     * 查询事件统计（查时序数据库）
     */
    public EventStatistics getEventStatistics(
        DeviceId deviceId,
        LocalDateTime from,
        LocalDateTime to
    ) {
        return timeSeriesQueryService.queryEventStatistics(deviceId, from, to);
    }
}
```

### 聚合级别枚举

```java
public enum AggregationLevel {
    MINUTE_5("5m", 5),
    MINUTE_30("30m", 30),
    HOUR_1("1h", 60),
    DAY_1("1d", 1440),
    WEEK_1("1w", 10080);

    private final String interval;
    private final int minutes;

    AggregationLevel(String interval, int minutes) {
        this.interval = interval;
        this.minutes = minutes;
    }

    public String getInterval() {
        return interval;
    }

    public int getMinutes() {
        return minutes;
    }
}
```
